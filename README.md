# Gereksiz Karar Çarkı (The Indecision Wheel)

React, Vite ve saf CSS kullanılarak geliştirilmiş; kararsız anlarınızı şansa bırakmanızı sağlayan modern, koyu temalı (Dark Mode) karar çarkı uygulaması.

## Özellikler

- **Dinamik Seçenek Yönetimi:** İstediğiniz kadar seçenek ekleyebilir, silebilir veya varsayılan listeye sıfırlayabilirsiniz.
- **Akıcı SVG Çark & Fizik Animasyonu:** Birikimli rotasyon açısı ve özel cubic-bezier yavaşlama eğrisi ile gerçekçi çark dönüşü.
- **Kutlama Efekti:** Kazanan seçenek belirlendiğinde konfeti patlaması ve sonuç modalı.
- **Responsive Tasarım:** Masaüstü ve mobil cihazlarla tam uyumlu koyu arayüz.

## Kurulum ve Çalıştırma

```bash
npm install
npm run dev
```
